# SentientSense prototype

A feedback-rewards application concept with a Solidity token-contract prototype.

## Implemented

- [`blockchain/contracts/SenuCoin.sol`](blockchain/contracts/SenuCoin.sol): token-contract source.

## Proposed, not implemented

Conversational feedback collection, AI chatbot integration, sentiment analysis, a web application and reward-redemption services are design ideas. This repository does not contain an LLM application, evaluation framework or completed backend.

This is historical exploratory work and is not part of an active implementation roadmap. No deployment or contract audit is claimed.
